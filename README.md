# TagdiBody support site

The support and privacy pages for the TagdiBody iPhone app, published with
GitHub Pages at https://pf25.github.io/tagdibody-support/

This repository is PUBLIC because GitHub Pages will not serve from a private
repository on a free plan, and because the App Store requires both pages to
be reachable by anyone. The app's source stays in its own private repository.

The source of truth for these files is `site/` in the app repository. Edit
them there and run `scripts/publish-site.sh`, or the two will drift.
